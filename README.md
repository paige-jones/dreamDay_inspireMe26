# Dream Day 26

## Project Overview
This project, **Dream Day 26**, was created for the Dream Day events. It is a web-based project designed using **Bootstrap 5**, **HTML**, and **CSS** to teach students basic web development concepts in a fun and exciting way.

## Technologies Used
- **Bootstrap 5**
- **HTML**
- **CSS**

## Author
**Paige Jones**.

## How to Use
1. Clone or download the repository.
2. Open the `index.html` file in your browser to view the project.
3. Change styles in `styles.css`. Animations are located in the `animations/animation-styles.css`.
4. Customize or extend the project as needed.
